# Assumptions & Limitations

## Base-Case Assumptions

| Input | Base Case |
|---|---:|
| WACC | 10.23% |
| Terminal Growth | 5.00% |
| Reference Market Price | ₹5,000 |
| Forecast Period | FY26E–FY30E |

The complete assumption set is contained in the `Assumptions` and `WACC` sheets of the workbook.

## Market Inputs

The workbook contains market-sensitive inputs including the risk-free rate, beta and equity risk premium.

For a live valuation, these inputs should be refreshed using current, independently verifiable sources and the source/date should be recorded.

## Historical Data Limitations

The final model preserves and discloses identified historical discrepancies rather than modifying historical figures solely to force reconciliation.

### Balance Sheet

Historical discrepancies were identified for:

- FY24: ₹20.90 Cr
- FY25: ₹11.60 Cr

The forecast balance sheet reconciles.

### D&A

Historical D&A differences were identified for:

- FY22: ₹25.60 Cr
- FY23: ₹40.00 Cr

These are documented in the workbook.

## Interpretation

The DCF output is highly sensitive to WACC and terminal growth. The sensitivity sheet should therefore be considered alongside the base case rather than treating the intrinsic value as a precise point estimate.

The model is intended for educational and portfolio demonstration purposes.
